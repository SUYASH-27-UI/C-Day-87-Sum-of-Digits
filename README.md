# C Day 87 - Sum of Digits

## Description
This C program calculates the sum of the digits of a positive integer using a while loop.

## Example
**Input:** `1234`

**Output:** `Sum of digits: 10`

## Concepts Used
- While Loop
- Modulus Operator
- Integer Division
- Addition
- Variables

## How to Run
1. Save the code as `sum_of_digits.c`.
2. Compile it using a C compiler.
3. Run the program and enter a positive integer.
